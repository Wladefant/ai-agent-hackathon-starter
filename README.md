## Die drei Sätze, die den Tag entscheiden

> **1. Baut mit M365 Copilot.**
> Nur das führt heute in den produktiven Einsatz. GitHub Copilot läuft für Fachbereiche nur
> lokal — schöne Demo, danach unbenutzbar. Ausnahme: Entwickler:in im Team und der Use Case
> liegt bei Code, Repos oder Pull Requests.

> **2. Euer Agent legt vor — ein Mensch schickt ab.**
> Die meisten Agenten können heute lesen, aber nicht schreiben. Kein Ticket anlegen, kein
> SharePoint ändern. Baut den letzten Schritt als Vorschlag. Wenn Schreibzugriff kommt,
> schaltet ihr genau diesen einen Schritt durch — der Rest bleibt wie er ist.

> **3. Ein guter Prompt ist ein gültiges Ergebnis.**
> Ein durchdachter Prompt, den ab morgen zwanzig Leute benutzen, schlägt einen halbfertigen
> Agenten, den niemand anfasst. Niemand muss um 19 Uhr ein Produkt haben.
